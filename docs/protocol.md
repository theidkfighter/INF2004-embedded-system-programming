# Wire protocol (Change Requirement 1)

Generated by `tools/evidence/gen_docs.py` from the JSON that `tests/host/build/wire_dump` prints (`wire_ids.h` tables and the frame layouts). The robot and both laptop codecs are compared with the same output by the host tests.

**Format_Version: 1.** Byte 0 bits 7..4 carry it in all seven payload types. Versions 4 and 5 are never assigned, because the Baseline_Build text commands start with 'A'..'Z'. Bits are written most significant first, a field may cross a byte boundary, multi-byte values are big-endian by that order, `F32` is IEEE-754 MSB first, padding bits are 0. Robot time is M24 ms. Field widths and ranges per field: [data_representation.md](data_representation.md).
