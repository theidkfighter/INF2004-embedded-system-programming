Commands

After an E-stop the robot only recovers with BTN1 on the robot (RESUME over MQTT is refused by design). Send barcode = remote override (FR19) for bench tests: the robot performs the mapped movement at once (a scanned barcode waits for the junction). A-Z only, accepted only while LINE_FOLLOWING. Start works from IDLE.

Barcode mapping (sent to the robot over MQTT)

Type the four letters the instructor gives (A-Z). The mapping is kept on the broker (retained on is02/map), so the robot gets it again after a restart or reconnect. A letter that is not in the map is reported and the car carries straight on.
